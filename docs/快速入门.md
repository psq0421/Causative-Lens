# 快速入门

> **一次会话，是运行中程序写给未来自己的信；CausativeLens 替你保存信封、时间戳和指纹。**

本指南覆盖 Windows 上 v0.1.0 的完整只读观测玩法。

## 1. 安装

双击对应架构的安装包。安装器会：

1. 让你选择 English、简体中文或繁體中文；
2. 为当前用户安装 GUI、CLI、daemon 和 capture；
3. 幂等写入用户级 PATH；
4. 注册 `.cllens`、HKCU App Paths，以及开始菜单/桌面快捷方式；
5. 检查 WebView2，缺失时引导官方 bootstrapper；
6. 提供“立即重启/稍后”选项，因为 PATH 和 shell 注册需要重启才能让新进程看见。

安装过程不应要求管理员权限。只有实时 ETW 采集需要时，capture 才会触发 UAC。

## 2. 检查安装

```powershell
clens --version
clens doctor
clens doctor --json
```

健康结果会报告 `mode: observe` 与 `installation: installed`。JSON 字段保持英文稳定，方便脚本。

人类文案可以选择语言：

```powershell
clens --lang en-US doctor
clens --lang zh-CN doctor
clens --lang zh-TW doctor
$env:CAUSATIVELENS_LANG = 'en-US'
```

## 3. 开始实时观测

嵌入式模式会拉起 Agent 子进程并覆盖完整生命周期：

```powershell
clens run -- your-agent.exe --config config.yaml
```

观测已有进程树：

```powershell
clens attach --pid 12345
```

v0.1.0 的边界是只读。CausativeLens 记录元数据和轨迹，不注入、不修改、不执行干预，也不替 Agent 做决策。

## 4. 查看会话

```powershell
clens watch
clens timeline
clens timeline --json
clens export --json
```

也可以使用桌面快捷方式打开 GUI。四个工作区与 CLI 对齐：Sessions（会话与健康度）、Timeline（断言、ETW 事件、水位线）、Graph（证据边与因果断点）、Replay / Query（受限 why、观测结果叠加、JSON 导出）。GUI 不直连引擎 crate，而是和 CLI 一样访问 daemon；两扇窗口可以有不同字体，却必须共享同一份证据。

## 5. 询问 why

查询路由是确定性的，离线可用，并识别中英文：

```powershell
clens why --path config.yaml
clens why "why did it modify config.yaml?"
clens why "为什么它修改了 config.yaml？"
clens why "為什麼它修改了 config.yaml？"
clens why "when did step 12 connect api.example.com:443"
clens why --path config.yaml --json
```

结果固定有五段：触发断言、证据事件、履约判定、反向归因、置信度/健康度。无法识别的自然语言会回退到 `clens why --path <p>`，不会凭空编造查询。

## 6. 打开与回放

```powershell
clens open path\to\session.cllens
clens replay --baseline baseline.json --branch branch.json
clens replay --baseline baseline.json --branch branch.json --json
```

v0.1.0 的回放是只读叠加：比较两次观测并高亮差异；反事实模拟属于 v2。

## 7. Harness 日志与适配器

输入是 append-only JSONL。内置适配器支持 DeepSeek 风格事件与通用 JSONL Tier3 兜底。运行时描述覆盖计划中的 Agent 生态，但不会因为未知版本强制阻断。daemon doctor 和适配器 fixture 会告诉你当前是已验证字段样本还是兜底解析。

日志轮换、截断、未知字段和解析失败都会进入健康度或 quarantine，不会悄悄丢掉线索。

## 8. 排查

| 现象 | 操作 |
|---|---|
| 安装后找不到 `clens` | 重启终端或选择安装器“立即重启”，检查用户 PATH。 |
| GUI 显示离线 | 启动 `clens-daemon.exe` 后重试；离线模式仍可打开本地只读界面。 |
| `CL-1001` | GUI/CLI 用标准用户运行，只有 capture 需要 UAC；按错误文案修复。 |
| `CL-2001` | capture 连续三次心跳失联，保留 spool 与健康报告。 |
| 缺少 WebView2 | 运行官方 Evergreen bootstrapper 后重启 GUI。 |
| 卸载有锁定文件 | 重启；卸载器会将文件移入 `.trash` 并重试。 |

## 10. 干净卸载

可以从“设置 > 应用 > 已安装的应用 > CausativeLens”卸载，也可以运行：

```powershell
& "$env:LOCALAPPDATA\causativelens\uninstall.exe" /S /NORESTART /CLEANUSERDATA
```

E2E 闸门会检查文件、注册表、用户 PATH、`.cllens` 关联和快捷方式全部清空。会话数据只有在勾选或传入 `/CLEANUSERDATA` 后才会删除。
