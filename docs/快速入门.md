# v0.2.5：快速入门

语言切换：[English](quick-start.md) · [简体中文](快速入门.md) · [繁體中文](快速入門.md)

> 一次观测，是程序写给未来自己的信。先让脚印清晰，再让结论诚实。

v0.2.5 是 Windows 上的只读 Agent 轨迹观测器。它读取 Agent 的结构化轨迹，把推理意图编译为因果断言，并把可见的系统证据与断言放在同一条时间轴上。v1.0.0 之前的版本均为 beta/测试版；当前版本坚持 observe-only，不启动 Agent、不修改 Agent 配置、不执行干预。

## 1. 安装与自检

双击对应架构的安装包。安装器为当前用户安装 CLI、GUI、daemon 与 capture，写入用户级 PATH，注册 `.cllens` 文件关联和快捷方式，并检查 WebView2。安装默认不需要管理员权限；只有真实 ETW 采集启动时，capture 才会请求 UAC。

```powershell
clens --version
clens doctor
clens doctor --json
```

CLI 支持三种界面语言：

```powershell
clens --lang en-US doctor
clens --lang zh-CN doctor
clens --lang zh-TW doctor
$env:CAUSATIVELENS_LANG = 'en-US'
```

## 2. 从 GUI 开始监听

1. 打开 **监听 → 请选择你使用的软件**，选择 OpenClaw、Claude Code、Codex 或其他模板。
2. 点击 **浏览**，选择项目、日志或安装目录；需要时取消“读取已有近期轨迹”，只监听新追加内容。
3. 点击 **检查目录**，确认实际扫描根与候选文件，再点击 **开始监听**。

模板按内容识别，不强制锁定厂商版本。未知 schema、截断文件和坏 JSON 都会进入健康度计数；程序不会把“选中了目录”冒充成“已经捕获到事件”。当前 GUI 监听流主要验证 Agent 轨迹接入；没有真实 ETW 证据时，履约判定保持“未观测到”。

## 3. 20 个模板

17 家产品包含 WorkBuddy 国内版和国际版两个独立模板，另有 DeepSeek Harness 与 Others 通用模板。每个模板都允许用户重新选择目录；云端任务、WSL、容器和远程网关只能通过其导出的本地轨迹接入，不能被宣传为本机 ETW。

| 模板 | 推荐输入 |
|---|---|
| Hermes Agent | session export 或 observer 日志；只有 state.db 时先导出 |
| Claude Code | message、tool_use、CLI stream-json 或 transcript |
| OpenAI Codex | exec JSONL 与 session trace |
| Google Antigravity CLI | 当前版本导出的结构化轨迹 |
| OpenClaw | gateway session transcript；健康日志本身不产生工具断言 |
| Manus | task activity export；云端报告不是本机系统证据 |
| AutoGPT | 实际 worker 的任务日志，分别确认 Classic/Platform/容器变体 |

| WorkBuddy（国内版） | 国内版任务活动导出，与国际版分开识别 |

## 4. 时间线、查询与回放

- **全部 / 断言 / 文件 / 网络** 是真实记录筛选器；搜索会与筛选器叠加。
- **来源**区分 Agent 报告、提取出的意图和系统证据。没有 ETW 连接时，系统证据为空。
- 点击记录或按 Enter/Space 查看 JSON 详情，按 Escape 关闭；导出保存当前视图。
- **Graph** 只展示已提取的意图与真实证据边，不凭空补边；**Query** 使用完整路径请求 daemon 的五段式 why 链。
- 停止监听会释放 reader 但保留当前视图；关闭 GUI 后 daemon 仍可继续读，退出 daemon 会清空内存视图。请尽早导出，JSON 导出不是持久化的 `.cllens` 会话文件。

## 5. Others 通用输入

在所选目录创建 `trace.jsonl`，每行一个 JSON：

```jsonl
{"tool_name":"read","args":{"path":"C:\\demo\\config.yaml"}}
{"tool_name":"connect","args":{"target":"api.example.com:443"}}
```

这只验证轨迹接入，不证明实际发生了文件或网络 I/O。JSONL 必须等到完整行才解析；普通文本和 Markdown 仅作为文本展示。

## 6. 可选模型辅助

Jev、OpenAI-compatible、Anthropic-compatible 与 Ollama 只提供证据锚定的辅助解释，不能修改 Verdict、启动进程或执行干预。API key 优先通过环境变量或 stdin 提供，不写入 `settings.json`：

```powershell
clens assist --enable --provider jev --endpoint https://your-jev-endpoint.example/v1/chat/completions --model jev-causal
$env:CAUSATIVELENS_LLM_API_KEY = '仅在当前终端使用的密钥'
clens why --path config.yaml --assist
```

## 7. 故障排查与边界

目录无权限时重新选择可读目录；没有记录时导出日志或勾选用户明确选择的 profile 日志。检查健康度中的未知 schema、轮转、截断、队列和跳过字节。扫描上限为深度 6、8192 个条目、128 个文件、单文件 256 KiB、队列 4096、视图 5000 行。
