# T0061-卸载残留

- 闸门：G7
- 目标：卸载干净、可回滚、锁定文件可恢复，不能误删用户会话数据。
- 实现：NSIS `un.Main`、`un.RemoveUserPath`、`un.MoveToTrash`、`installer/installer-e2e.ps1`。
- 卸载顺序：停止 GUI/daemon/capture → 删除快捷方式 → 删除 Uninstall/App Paths/Classes → 删除用户 PATH token → 删除已知安装文件 → 可选清理 `.cllens/.clspool/sessions/spool/data` → `.trash/pending` 兜底 → Shell 通知。
- 五项自检：文件、注册表、PATH、`.cllens` 关联、快捷方式必须全部空；E2E 失败即退出非零。

## DoD

```powershell
powershell -ExecutionPolicy Bypass -File installer/installer-e2e.ps1 -InstallerPath dist/CausativeLens-setup-x64-dev.exe
```

- 证据：`dist/installer-e2e-report.json` 的 `uninstall-verify` 五项均为 `true`，并包含重装成功记录。
- 完成记录：已完成。已实测空格/中文路径、静默卸载、PATH 去重/移除、OneDrive Desktop 路径、五项残留与重装。
- 遗留：需要锁文件进程和 VM 重启场景在 CI Windows runner 再演练；当前本机已验证正常锁定路径与无锁路径。
