# T0083 Windows ETW 采集第 7 章复检

- 闸门：G1
- 范围：蓝图 7.1–7.11，会话、权限、keyword、解码、FileObject、rundown、重排、过滤、丢失和 GUID 自检。
- 状态：契约补齐；真实 ETW/TDH/UAC 运行态仍需 Windows 提权 runner。
- 契约：`docs/spec/etw-7.md`
- 审计：`docs/plan/etw-audit-7.md`

## 已实施

1. ProviderContract/GUID/keyword 白名单模型。
2. 启动前同名会话停止与删除，部分失败回滚。
3. 显式 rundown 控制状态。
4. PID include-only/excluded 过滤模型。
5. EventsLost/RealTimeBuffersLost/drop 健康度计数。
6. 对应 Rust 契约测试。

## 未完成且禁止宣称通过

- `EVENT_RECORD` 手工解码、TDH oracle 和 golden 对照；
- provider rundown keyword、PID PASS_FILTER、ACL 降权、CL-1001；
- 28 分片 FileObject、TTL/LRU、mmap ring、QueryTrace 500ms 轮询和 80%/95% 背压策略。
