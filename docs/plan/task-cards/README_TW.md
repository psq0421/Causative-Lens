# 任務卡目錄

任務卡是 G0–G7 的可執行清單。每張卡保留原始 `T0xxx` 編號、可複製 DoD 命令和完成記錄。

語言：[English](README.en-US.md) · [简体中文](README.md) · [繁體中文](README_TW.md)。

| 閘門 | 任務卡 |
|---|---|
| G0 | T0001–T0005 |
| G1 | T0010–T0015 |
| G2/G5 | T0020–T0023 |
| G3 | T0030–T0032 |
| G4 | T0040–T0041 |
| G6 | T0050–T0052 |
| G7 | T0060–T0072 |
| 架構複檢 | T0080–T0087 |

開啟任意 `T*.md` 查看驗收命令和證據路徑。任務卡是小承諾，閘門報告是它在 Windows 上經受現實後的證明。
