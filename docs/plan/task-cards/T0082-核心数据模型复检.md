# T0082 核心数据模型复检

- 闸门：G2/G3
- 范围：蓝图 6.1–6.5 的 SysEvent、Assertion、Verdict、ID、路径驻留和 SQLite 映射。
- 状态：已完成代码补齐与契约测试；QPC 锚点接入和 session 文件主键迁移列入 OQ-017/OQ-018。
- 契约：`docs/spec/data-model-6.md`
- 审计：`docs/plan/data-model-audit-6.md`

## 实施内容

1. `clens-types` 增加 `HarnessSpan`、`order_key`、`Fulfilment`、`ScoreComponents`、`EvidenceEdge`、`Deviation`、`Watermark`、`Verdict` 和稳定 ID 函数。
2. `clens-harnessd::AssertionPool` 使用稳定 ID，并将矛盾状态保留在池索引，不写进跨模块 IR。
3. `clens-capture` 增加 `PathInterner` 与 `SequenceAllocator`，补齐路径驻留和 capture 侧序列号契约。
4. `clens-core` 提供公共模型别名、watermark 纯函数和候选到 Verdict 的转换。
5. SQLite DDL 为跨模块表增加 `schema_v`，保留 observe-only 的干预/决策空表。
6. `ClockAnchor` 增加 QPC→UTC 100 ns/毫秒的饱和换算，避免调用方把原始 QPC 当 Unix 时间。
