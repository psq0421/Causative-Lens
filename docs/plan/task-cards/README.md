# 任务卡目录

任务卡是 G0–G7 的可执行清单。每张卡保留原始 `T0xxx` 编号、可复制 DoD 命令和完成记录。

语言：[English](README.en-US.md) · [简体中文](README.md) · [繁體中文](README_TW.md)。

| 闸门 | 任务卡 |
|---|---|
| G0 | T0001–T0005 |
| G1 | T0010–T0015 |
| G2/G5 | T0020–T0023 |
| G3 | T0030–T0032 |
| G4 | T0040–T0041 |
| G6 | T0050–T0052 |
| G7 | T0060–T0072 |
| 架构复检 | T0080–T0087 |

打开任意 `T*.md` 查看验收命令和证据路径。任务卡是小承诺，闸门报告是它在 Windows 上经受现实后的证明。
