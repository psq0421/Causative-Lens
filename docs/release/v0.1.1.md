# v0.1.1 Beta — a clearer path to the first trace

[English](#english) · [简体中文](#简体中文)

## English

This candidate turns local trace ingestion into a guided workflow: **Listen → select software → choose folder → inspect detection → start**. Twenty choices cover the requested 17 products, separate WorkBuddy channels, DeepSeek and Others. Actual compatibility depends on the trace format; unknown versions are not blocked by name.

- Rebuilt the original Fluent interface with a three-step wizard, useful empty/waiting states, health counters and light/dark appearance.
- Fixed Timeline All/Assertions/Files/Network to filter actual daemon records. Added counts, combined search, keyboard details, follow control, bounded virtual scrolling and JSON export.
- Added a bounded local reader, partial-line handling, snapshot imports, rotation/truncation handling, and explicit source labels. Tool results do not duplicate tool-call assertions.
- Fixed the CLI shortcut: it now opens `cmd.exe /D /K`, shows help and leaves a usable prompt, including quoted Unicode/space paths.
- Kept English (US), Simplified Chinese and Traditional Chinese, one daemon/two frontends, and observe-only behavior.

Validation on this Windows x64 machine: 112 Rust tests, strict clippy/fmt, three frontend model tests, synthetic-log browser E2E using the real daemon, Tauri release build, silent installation/overwrite/uninstallation/reinstallation and five residual checks. New Rust monitoring modules: 87.08% line coverage. Browser append-to-visible latency: 603ms in the recorded sample. Installer size: 2,292,236 bytes before any further signing.

Limits: synthetic fixtures do not certify real vendor releases. No live ETW connection in this listening workflow; no complete `.cllens` persistence, Agent launch, or remote/WSL kernel collection. Views live in daemon memory until exported. Native-window creation is a smoke test, not a cold-start performance measurement. FPS/RSS, clean-VM reboot matrix, fuzz/audit/deny and production signing remain release gates. ARM64 is deferred. This is an unsigned `-dev` candidate, **not a signed production release**.

## 简体中文

这次把本机轨迹接入改成可操作的向导：**监听 → 选择软件 → 选择目录 → 检查识别 → 开始**。提供 17 家产品、WorkBuddy 两渠道、DeepSeek 与 Others 共 20 个选择项。按轨迹内容识别，不因版本陌生而强制拒绝。

- 重做原创 Fluent 界面：三步向导、明确的等待与空态、健康计数、深浅色。
- 修复 Timeline 全部/断言/文件/网络的真实筛选，增加计数、搜索、键盘详情、跟随控制、有界虚拟滚动与 JSON 导出。
- 新增有界只读读取器，处理半行、多行 JSON 快照、轮换/截断，明确区分来源；工具结果不重复提取工具调用断言。
- 修复 CLI 快捷方式：`cmd.exe /D /K` 显示帮助后保留提示符，正确引用空格/Unicode 路径。
- 保持三语、一 daemon 两前端、observe-only。

本机 Windows x64 验证：112 项 Rust 测试、严格 clippy/fmt、3 项前端模型测试、真实 daemon + 合成日志浏览器 E2E、Tauri release 构建，以及静默安装/覆盖/卸载五查/重装。新增 Rust 监听模块行覆盖率 87.08%；记录的浏览器追加可见延迟为 603ms；安装器 2,292,236 字节（签名前）。

限制：合成样例不等于真实厂商版本认证。当前监听不连接实时 ETW，未实现完整 `.cllens` 持久化、拉起 Agent 或远端/WSL 内核采集。视图保留在 daemon 内存，请及时导出。创建原生窗口只证明程序能打开，不是冷启动性能证据。FPS/RSS、干净 VM 重启矩阵、fuzz/audit/deny 与正式签名仍是发布门槛；ARM64 暂缓。这是未签名 `-dev` 候选，**不是已签名正式发布**。
