## 誠實邊界

The local package is x64-first. ARM64 runtime evidence, a clean-VM matrix, Azure Trusted Signing, reboot validation, and real kernel-capture performance remain separate release evidence gates. The local installer is explicitly `unsigned-dev`; no self-signed certificate is used as a production substitute. GUI cold-start in this E2E is a native-window smoke measurement only, not the full `<600 ms` performance claim.

The install E2E used a temporary path containing spaces and Chinese characters. It verified version `0.2.5`, `mode=observe`, and `status=ok` from `clens doctor --json`. The five uninstall checks (`files`, `registry`, `path`, `association`, `shortcuts`) were all true, followed by a successful reinstall.

> A release is a promise with receipts. This report keeps the receipts and the unmeasured edges visible.
