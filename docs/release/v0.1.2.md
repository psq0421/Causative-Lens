# CausativeLens v0.1.2 Beta

语言切换：[English (US)](v0.1.2.en-US.md) · [简体中文](v0.1.2.md) · [繁體中文](v0.1.2_TW.md)。

## 发布性质

`v0.1.2` 按维护者要求作为 GitHub 普通 Release 发布，不勾选 pre-release。产品在 `v1.0.0` 之前仍属于测试软件；本版本不能被解释为 ETW 生产闭环或 Jev 决策后端已经完成。

## 新增能力

- `clens-assist` 统一 CLI、GUI 和 daemon 的可选辅助分析通道。
- Jev、OpenAI-compatible、Anthropic-compatible、本机 Ollama provider。
- GUI“设置”工作区：模型、Endpoint、token、温度、超时、路径脱敏、raw quote、自动分析、时间线刷新、保留数量、语言和主题。
- CLI：`clens assist --enable`、`clens assist --disable`、`clens why --assist`。
- 模型输出强制证据引用；引用不存在时输出 `grounded: false`，不会改写履约判定。
- CLI 人类输出改为分层字段格式，JSON 输出保持机器契约稳定。

## 安全与隐私

API key 不写入 `settings.json`，只在当前 CLI/GUI 进程或一次 RPC 请求中存在。路径默认替换为稳定哈希，`raw_quote` 默认不发送。只允许 HTTP(S) Endpoint，并拒绝包含控制字符的 header 输入。辅助层只解释已经生成的 observe-only 因果链，不能启动进程、修改 Verdict 或执行干预。

## 已知边界

当前 x64 本机构建可安装和运行；ARM64 暂不随本次本机包交付。上传的 x64 安装包明确标记为未签名，因为构建机没有 Azure Trusted Signing 凭据；没有用自签名证书冒充正式签名。真实 ETW/TDH/mmap ring/.clspool 生产闭环仍按 [v0.1.2 证据级方案](../plan/v0.1.2.md)继续验收。`run`/`attach` 和 Jev 决策后端仍不应被宣传为已完成。
