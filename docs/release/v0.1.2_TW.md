# CausativeLens v0.1.2 Beta

語言切換：[English (US)](v0.1.2.en-US.md) · [简体中文](v0.1.2.md) · [繁體中文](v0.1.2_TW.md)。

本版本依維護者要求以 GitHub 普通 Release 發佈，不勾選 pre-release。`v1.0.0` 之前仍是測試軟體；本版本不宣稱 ETW 生產閉環或 Jev 決策後端已完成。

新增 `clens-assist`、Jev/OpenAI-compatible/Anthropic-compatible/Ollama、GUI「設定」工作區、`clens assist`、`clens why --assist`、證據引用校驗與可讀 CLI 輸出。API key 不落盤，路徑預設脫敏，輔助層只能解釋 observe-only 因果鏈。

本機可安裝 x64 建置，ARM64 暫不包含。上傳的 x64 安裝包明確標記為未簽名，因為建置機沒有 Azure Trusted Signing 憑據；沒有使用自簽名憑證冒充正式簽名。真實 ETW/TDH/mmap ring/.clspool 生產閉環依 [v0.1.2 方案](../plan/v0.1.2.md)持續驗收。
