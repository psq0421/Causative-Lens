# CausativeLens v0.2.5 (Beta)

> **This is the largest update in the project's history so far.**

v0.2.5 expands the GUI from a small graph-and-settings shell into a complete investigation surface while preserving the central idea: compile an agent's stated intent into causal assertions, then show what the available evidence can and cannot prove.

## Highlights

- Added the seven-stage GUI journey: **Sessions → Observe → Investigate → Replay → Compare → Assist → Intervention**.
- Added a Windows-style menu bar, keyboard shortcuts, breakpoint-first investigation cards, replay controls, compare views, and evidence-grounded assistance.
- Added persistent health indicators for `EventsLost`, TDH fallback, quarantine, dropped events, and late reorder events, plus daemon/capture status.
- Added architecture contracts for seven workspaces, seven menu groups, observe-only intervention locking, and the RPC-only GUI boundary.
- Added English (US), Simplified Chinese, and Traditional Chinese UI/documentation links.
- Unified Rust crates, CLI, GUI, Tauri metadata, installer scripts, payload manifests, and lockfile on `0.2.5`.
- Refreshed the quick-start and 20-template monitoring guides, including Hermes Agent, Claude Code, Codex, OpenClaw, Manus, and Others.

## CLI and GUI parity

Every visible GUI action maps to an existing RPC or clearly points to the CLI-authoritative path. The GUI remains a window onto the daemon, never a second engine. Observe-only mode is still enforced: intervention and decision commands are not registered.

## Validation

The local x64 gates passed:

```powershell
cargo fmt --all -- --check
cargo test --workspace --offline
cargo clippy --workspace --all-targets --offline -- -D warnings
node --check crates/clens-gui/frontend/app.js
node --check crates/clens-gui/frontend/i18n.js
```

The x64 `-dev` installer passed local install, doctor, GUI smoke, PATH idempotence, uninstall residue checks, and reinstall. ARM64 runtime evidence, clean-VM evidence, Trusted Signing, and real kernel-capture measurements remain explicit release evidence gates.

## Release boundary

All versions before `v1.0.0` are beta/test software. v0.2.5 remains observe-only. The intervention schema stays forward-compatible, but no intervention or decision write path is registered. Without Azure Trusted Signing credentials, an installer is named and documented as `unsigned-dev`; it must not be presented as a signed production binary.

The lens is a lantern: it makes the footprint legible, then leaves the road untouched.
