# CausativeLens v0.1.2 Beta

Language switch: [English (US)](v0.1.2.en-US.md) · [简体中文](v0.1.2.md) · [繁體中文](v0.1.2_TW.md).

## Release status

At the maintainer's request, `v0.1.2` is published as a normal GitHub Release with pre-release disabled. Every version before `v1.0.0` remains test software; this release does not claim that the production ETW pipeline or the Jev decision backend is complete.

## What changed

- Added `clens-assist`, a shared optional analysis path for CLI, GUI, and daemon.
- Added Jev, OpenAI-compatible, Anthropic-compatible, and local Ollama providers.
- Added the GUI **Settings** workspace for provider, model, endpoint, token, temperature, timeout, path redaction, raw quotes, automatic analysis, timeline refresh, retention, language, and theme.
- Added `clens assist --enable`, `clens assist --disable`, and `clens why --assist`.
- Enforced evidence citations: a finding that cites an assertion or event absent from the submitted chain is returned as `grounded: false`.
- Reformatted human CLI output while keeping JSON machine contracts stable.

## Security and privacy

API keys never enter `settings.json`; they remain in the current CLI/GUI process or one RPC request. Paths are replaced with stable hashes and `raw_quote` is omitted by default. Only HTTP(S) endpoints are accepted, and control characters in header values are rejected. The assistant explains an existing observe-only causal chain; it cannot launch processes, mutate Verdicts, or execute intervention.

## Known boundaries

The x64 local build can be installed and exercised on this machine; ARM64 is not included in this local package. The uploaded x64 installer is explicitly marked unsigned because Azure Trusted Signing credentials were not available on the build host; no self-signed certificate is presented as a production signature. The real ETW/TDH/mmap ring/.clspool production closure remains under the evidence plan in [v0.1.2 plan](../plan/v0.1.2.en-US.md). `run`/`attach` and the Jev decision backend must not be advertised as complete.
