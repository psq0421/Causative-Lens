# CausativeLens v0.2.5（测试版）

> **这是该项目迄今最大的一次更新。**

v0.2.5 把 GUI 从简单的 Graph 与 Settings 壳扩展成完整的探查界面，同时保留产品的核心承诺：把 Agent 说出的意图编译成因果断言，再明确展示现有证据能够、以及不能够证明什么。

## 主要变化

- 新增七段式 GUI 用户旅程：**会话 → 观测 → 探查 → 回放 → 对比 → 辅助 → 干预**。
- 新增 Windows 风格菜单栏、快捷键、断点优先探查卡、回放控制、双会话对比和证据锚定辅助分析。
- 常驻显示 `EventsLost`、TDH fallback、quarantine、dropped、late reorder 等健康度指标，以及 daemon/capture 状态。
- 增加七工作区、七组菜单、observe-only 干预锁定和 GUI 仅走 RPC 的架构契约。
- 补齐 English (US)、简体中文、繁體中文界面和文档入口。
- Rust crate、CLI、GUI、Tauri 元数据、安装器脚本、payload manifest 与 lockfile 统一为 `0.2.5`。
- 更新快速入门与 20 个监听模板，覆盖 Hermes Agent、Claude Code、Codex、OpenClaw、Manus 与 Others。

## CLI 与 GUI 对等

每个可见 GUI 动作都映射到既有 RPC，或明确指向 CLI 权威入口。GUI 只是 daemon 的窗口，不复制第二套引擎。observe-only 仍然有效：干预族和决策族命令不注册。

## 验证

本机 x64 门禁通过：

```powershell
cargo fmt --all -- --check
cargo test --workspace --offline
cargo clippy --workspace --all-targets --offline -- -D warnings
node --check crates/clens-gui/frontend/app.js
node --check crates/clens-gui/frontend/i18n.js
```

x64 `-dev` 安装包通过本机安装、doctor、GUI smoke、PATH 幂等、卸载残留检查和重装。ARM64 运行证据、干净 VM、Trusted Signing 与真实内核采集测量仍单独列为发布证据门槛。

## 发布边界

`v1.0.0` 之前的所有版本都是 beta/测试版。v0.2.5 仍为 observe-only；干预 schema 保持前向兼容，但没有干预或决策写入路径。构建机没有 Azure Trusted Signing 凭据时，安装包必须命名并记录为 `unsigned-dev`，不能冒充已签名生产程序。

这盏镜头先把脚印照亮，再把道路原样留给被观测的程序。
