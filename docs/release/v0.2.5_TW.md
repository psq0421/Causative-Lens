# CausativeLens v0.2.5（測試版）

> **這是本專案迄今最大的一次更新。**

v0.2.5 將 GUI 從簡單的 Graph 與 Settings 外殼擴展成完整的探查介面，同時保留產品的核心承諾：把 Agent 說出的意圖編譯成因果斷言，再清楚展示現有證據能夠、以及不能夠證明什麼。

## 主要變更

- 新增七段式 GUI 使用者旅程：**工作階段 → 觀測 → 探查 → 回放 → 比較 → 輔助 → 介入**。
- 新增 Windows 風格功能表、快捷鍵、斷點優先探查卡、回放控制、雙會話比較與證據錨定輔助分析。
- 常駐顯示 `EventsLost`、TDH fallback、quarantine、dropped、late reorder 等健康度指標，以及 daemon/capture 狀態。
- 增加七個工作區、七組功能表、observe-only 介入鎖定與 GUI 僅走 RPC 的架構契約。
- 補齊 English (US)、简体中文、繁體中文介面與文件入口。
- Rust crate、CLI、GUI、Tauri 中繼資料、安裝器腳本、payload manifest 與 lockfile 統一為 `0.2.5`。
- 更新快速入門與 20 個監聽模板，涵蓋 Hermes Agent、Claude Code、Codex、OpenClaw、Manus 與 Others。

## CLI 與 GUI 對等

每個可見 GUI 動作都映射到既有 RPC，或明確指向 CLI 權威入口。GUI 只是 daemon 的視窗，不複製第二套引擎。observe-only 仍然有效：介入族與決策族命令不註冊。

## 驗證

本機 x64 門檻通過：

```powershell
cargo fmt --all -- --check
cargo test --workspace --offline
cargo clippy --workspace --all-targets --offline -- -D warnings
node --check crates/clens-gui/frontend/app.js
node --check crates/clens-gui/frontend/i18n.js
```

x64 `-dev` 安裝包通過本機安裝、doctor、GUI smoke、PATH 冪等、解除安裝殘留檢查與重裝。ARM64 執行證據、乾淨 VM、Trusted Signing 與真實核心擷取量測仍列為獨立發佈證據門檻。

## 發佈邊界

`v1.0.0` 之前的所有版本都是 beta/測試版。v0.2.5 仍為 observe-only；介入 schema 保持前向相容，但沒有介入或決策寫入路徑。建置機沒有 Azure Trusted Signing 憑據時，安裝包必須命名並記錄為 `unsigned-dev`，不能冒充已簽章的生產程式。

這盞鏡頭先把腳印照亮，再把道路原樣留給被觀測的程式。
