# CausativeLens v0.2.0 (Beta)

## What changed

- `clens-capture --live` now opens the four ETW realtime sessions through Windows `OpenTraceW` and `ProcessTrace`.
- Capture callbacks copy `EVENT_RECORD` metadata and raw user bytes; TDH reads field names and typed values, while FileObject-to-path interning, queue pressure, unknown events, and loss counters stay explicit in health.
- On Windows the daemon starts the elevated `clens-capture.exe` host from the installed directory when a monitor is started, receives the same JSON event IR, and feeds alignment plus SQLite. If the host is unavailable, the status says so explicitly.
- Added the WAL-backed SQLite `SessionStore`. Assertions, system-event metadata, evidence edges, and Verdicts survive process restarts; `session.open_existing` and `why` read the persisted graph.
- The GUI Graph is now a dual-lane Canvas for assertions and system facts, with bounded rendering and Fluent Design tokens.
- CLI and daemon support `local://jev` with `CAUSATIVELENS_JEV_COMMAND`; Jev remains evidence-only assistance.
- Added Causal Weave, a deterministic candidate tie-breaker combining temporal braid, process lineage, and contradiction penalty.
- Workspace, CLI, GUI, and installer scripts are aligned on `0.2.0`.

## Validation

```powershell
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --offline -- -D warnings
cargo test --workspace --offline
cargo check -p clens-capture --target x86_64-pc-windows-msvc --offline
cargo bench -p clens-core --bench alignment --offline
cargo bench -p clens-storage --bench spool_decode --offline
```

Local x64 release baseline (2026-10-31): 6.22–6.27 ns for `alignment/one_candidate`; 835.38–840.16 µs for `spool/recover_10k_frames`.

This release provides an x64 Windows build first. Windows 10 Build 10240+ and Windows Server 2016+ are the compatibility baseline. Without an administrator token, kernel evidence is reported as unavailable; Harness logs are never presented as ETW facts. `advise`, `enforce`, and the Jev decision backend remain unregistered.
