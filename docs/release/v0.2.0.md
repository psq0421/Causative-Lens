# CausativeLens v0.2.0（测试版）

## 这一版改变了什么

- `clens-capture --live` 通过 Windows `OpenTraceW`/`ProcessTrace` 接入四条 ETW realtime 会话。
- 采集回调复制 `EVENT_RECORD` 元数据和原始用户数据，TDH 读取字段名并按字段读取数值/文本；FileObject→Path 驻留、队列背压、未知事件和丢失计数都有明确 health 字段。
- daemon 在 Windows 安装目录找到 `clens-capture.exe` 后，会从监听 RPC 启动提权 capture host，接收同一 JSON 事件 IR 并写入对齐引擎与 SQLite；capture 不可用时状态明确显示为不可连接。
- 新增 WAL SQLite `SessionStore`，断言、系统事件元数据、证据边和 Verdict 会随会话落盘；`session.open_existing` 支持离线重开，`why` 可读取持久化图。
- GUI Graph 改为断言与系统事实双泳道 Canvas，保留虚拟化窗口和 Fluent Design token。
- CLI/daemon 支持 `local://jev` 与 `CAUSATIVELENS_JEV_COMMAND`，Jev 只做证据辅助分析。
- 新增 Causal Weave 确定性候选排序算法：时间编织、进程谱系与矛盾惩罚共同处理临界候选。
- workspace、CLI、GUI、installer 脚本版本统一为 `0.2.0`。

## 验证

```powershell
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --offline -- -D warnings
cargo test --workspace --offline
cargo check -p clens-capture --target x86_64-pc-windows-msvc --offline
cargo bench -p clens-core --bench alignment --offline
cargo bench -p clens-storage --bench spool_decode --offline
```

本机 x64 release 基线（2026-10-31）：`alignment/one_candidate` 6.22–6.27 ns；`spool/recover_10k_frames` 835.38–840.16 µs。

本版本首先提供 x64 Windows 构建。Windows 10 Build 10240+ 与 Windows Server 2016+ 是兼容基线。没有管理员令牌时，内核证据显示为不可见；不会用 Harness 日志替代 ETW 事实。`advise`、`enforce` 和 Jev 决策后端仍不注册。
