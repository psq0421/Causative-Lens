# CausativeLens v0.2.5：一盞看懂 Agent 的小燈

這幾天我們發佈了 CausativeLens v0.2.5——這是本專案迄今最大的一次更新。

用一句白話說：**Agent 說「我要做什麼」，CausativeLens 再去看「電腦實際發生了什麼」。**

例如 Agent 說：「我只讀一下 `config.yaml`。」CausativeLens 會把它變成可檢查的承諾，再對照系統看得見的記錄：有沒有讀取？是不是同一個程式？是否在合理時間內？有沒有寫入？最後回答「已履約、偏離、未觀測，還是證據暫時不可見」。

它不會代替 Agent 做決定，也不會偷偷修改檔案。v0.2.5 仍是 observe-only 測試版。

## 為什麼需要它？

我們看到 Agent 的回答，像看到一份計畫；看到系統日誌，像看到監視錄影。兩份資料分開時，很難知道「說的」和「做的」是否一致。

CausativeLens 把它們放在同一條時間線：Agent 的想法和工具呼叫變成因果斷言，Windows 的程序、檔案和網路記錄變成系統事實，兩者對齊後形成可追溯的因果履約圖。

## v0.2.5 更新了什麼？

GUI 從簡單的 Graph + Settings 外殼擴展為七個工作區：工作階段、觀測、探查、回放、比較、輔助，以及目前鎖定的介入工作區。它還加入 Windows 風格功能表、快捷鍵、健康度指示、三語文件與更完整的監聽流程。

若你問「它為什麼修改 `config.yaml`？」`why` 會固定回答五段：原始斷言、系統證據、履約判定、反向歸因，以及信心度與採集健康度。

## 這次有多少程式碼？

按照 v0.2.5 標籤的 Git 追蹤檔案統計：Rust 生產程式 12,589 行，Rust 測試/bench/fuzz 717 行，GUI 前端 1,500 行，安裝器與腳本 1,062 行，CI 95 行。可執行程式與腳本合計 15,868 行；含 CI 為 15,963 行。統計排除文件、依賴元資料、生成目錄、`target`、`dist` 與 `.git`。

這盞小燈不搶方向盤，只把 Agent 說過的話和電腦留下的腳印放在一起，讓你自己看清楚中間有沒有走樣。

> 讓程式留下腳印，讓人保留判斷。
