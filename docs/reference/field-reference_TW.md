# 欄位參考

跨模組核心資料是 `SysEvent`、`Assertion`、`Verdict`。每個結構帶 `schema_v`；`seq` 是 capture 全域單調序號，`assertion_id` 由日誌/行/槽位穩定計算。`.cllens` 保存索引與履約圖，`.clspool` 保存高頻原始事件。

JSON/RPC 欄位名、命令名、錯誤碼與副檔名不隨介面語言變化。使用者文案依[語言支援](../guide/language-support_TW.md)選擇。
