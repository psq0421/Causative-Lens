# v0.2.5：快速入門

語言切換：[English](quick-start.md) · [简体中文](快速入门.md) · [繁體中文](快速入門.md)

> 一次觀測，是程式寫給未來自己的信。先讓腳印清楚，再讓結論誠實。

v0.2.5 是 Windows 上的唯讀 Agent 軌跡觀測器。它讀取 Agent 的結構化軌跡，把推理意圖編譯成因果斷言，並把可見的系統證據與斷言放在同一條時間軸上。v1.0.0 之前的版本都是 beta/測試版；本版本堅持 observe-only，不啟動 Agent、不修改 Agent 設定、不執行介入。

## 1. 安裝與自我檢查

雙擊對應架構的安裝包。安裝器會為目前使用者安裝 CLI、GUI、daemon 與 capture，寫入使用者級 PATH，註冊 `.cllens` 關聯與捷徑，並檢查 WebView2。安裝預設不需要系統管理員權限；只有啟動真實 ETW 擷取時，capture 才會要求 UAC。

```powershell
clens --version
clens doctor
clens doctor --json
```

CLI 支援三種介面語言：

```powershell
clens --lang en-US doctor
clens --lang zh-CN doctor
clens --lang zh-TW doctor
$env:CAUSATIVELENS_LANG = 'en-US'
```

## 2. 從 GUI 開始監聽

1. 開啟 **監聽 → 請選擇你使用的軟體**，選擇 OpenClaw、Claude Code、Codex 或其他模板。
2. 按 **瀏覽**，選擇專案、日誌或安裝資料夾；需要時取消「讀取既有近期軌跡」，只監聽新追加內容。
3. 按 **檢查資料夾**，確認實際掃描根與候選檔案，再按 **開始監聽**。

模板依內容識別，不強制鎖定廠商版本。未知 schema、截斷檔案和壞 JSON 都會進入健康度計數；程式不會把「選取資料夾」冒充成「已捕獲事件」。沒有真實 ETW 證據時，履約判定保持「未觀測到」。

## 4. 時間線、查詢與回放

- **全部 / 斷言 / 檔案 / 網路** 是真實記錄篩選器；搜尋會與篩選器疊加。
- **來源**區分 Agent 報告、提取的意圖與系統證據。沒有 ETW 連線時，系統證據為空。
- 點擊記錄或按 Enter/Space 查看 JSON 詳情，按 Escape 關閉；匯出保存目前視圖。
- **Graph** 只展示已提取的意圖與真實證據邊；**Query** 使用完整路徑請求 daemon 的五段式 why 鏈。
- 停止監聽會釋放 reader 但保留目前視圖；退出 daemon 會清空記憶體視圖。請儘早匯出，JSON 匯出不是持久化的 `.cllens` 會話檔案。

## 5. Others 通用輸入

在所選資料夾建立 `trace.jsonl`，每行一個 JSON：

```jsonl
{"tool_name":"read","args":{"path":"C:\\demo\\config.yaml"}}
{"tool_name":"connect","args":{"target":"api.example.com:443"}}
```

這只驗證軌跡接入，不證明實際發生檔案或網路 I/O。JSONL 必須等到完整行才解析；普通文字和 Markdown 僅作文字展示。

## 6. 可選模型輔助

Jev、OpenAI-compatible、Anthropic-compatible 與 Ollama 只提供證據錨定的輔助解釋，不能修改 Verdict、啟動程序或執行介入。API key 優先透過環境變數或 stdin 提供，不寫入 `settings.json`。

## 7. 故障排除與邊界

資料夾無權限時重新選擇可讀資料夾；沒有記錄時匯出日誌或勾選使用者明確選擇的 profile 日誌。檢查健康度中的未知 schema、輪替、截斷、佇列和跳過位元組。掃描上限為深度 6、8192 個條目、128 個檔案、單檔 256 KiB、佇列 4096、視圖 5000 行。
