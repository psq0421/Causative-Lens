# 快速入門

目前 v0.1.2 可用流程請見[初次監聽](guide/monitoring-start_TW.md)：選軟體 → 選目錄 → 檢查 → 監聽 → 篩選/詳情/匯出。下文保留 v0.1.2 原介面規劃。

> **一次工作階段，是執行中程式寫給未來自己的信；CausativeLens 替你保存信封、時間戳與指紋。**

本指南介紹 Windows 上 v0.1.2 的目標唯讀觀測流程。

> **Beta 現況，核查於 2026-10-26：** `run/attach` 目前回傳 `offline`，廠商轉換/自動 tail 與完整擷取/持久化尚未接通；`open` 只建立記憶體工作階段，不讀取指定檔案。以下含目標介面，請先看 [17 款產品詳細教程（简体中文）](guide/runtime-integration_CN.md)或 [English](guide/runtime-integration.md)的已驗證步驟。

## 1. 安裝

雙擊對應架構的安裝包。安裝器會提供三種語言、為目前使用者安裝 GUI/CLI/daemon/capture、幂等寫入使用者 PATH、註冊 `.cllens` 關聯與快捷方式，檢查 WebView2，並提供「立即重新啟動/稍後」選項。安裝不應要求系統管理員權限；只有即時 ETW 擷取需要時，capture 才會觸發 UAC。

## 2. 檢查安裝

```powershell
clens --version
clens doctor
clens doctor --json
clens --lang en-US doctor
clens --lang zh-CN doctor
clens --lang zh-TW doctor
```

健康結果會報告 `mode: observe` 與 `installation: installed`；JSON 欄位保持英文穩定。

## 3. 即時觀測目標介面（本 Beta 尚未接通）

以下命令目前僅回傳 `offline`，不會啟動 Agent 或完整擷取。

```powershell
clens run -- your-agent.exe --config config.yaml
clens attach --pid 12345
```

v0.1.2 僅唯讀：記錄中繼資料與軌跡，不注入、不修改、不執行介入，也不替 Agent 做決策。

## 4. 查看工作階段

目前 `watch/timeline` 不以票據選擇手工 RPC 工作階段，`export` 回傳 `offline`；空畫面不代表未發生行為。

```powershell
clens watch
clens timeline
clens timeline --json
clens export --json
```

GUI 的 Sessions、Timeline、Graph、Replay / Query 四個工作區與 CLI 對齊。GUI 只透過 daemon 工作；兩個前端可以有不同字體，卻共享同一份證據。

## 5. 詢問 why

```powershell
clens why --path config.yaml
clens why "why did it modify config.yaml?"
clens why "为什么它修改了 config.yaml？"
clens why "為什麼它修改了 config.yaml？"
clens why "when did step 12 connect api.example.com:443"
clens why --path config.yaml --json
```

結果固定包含觸發斷言、證據事件、履約判定、反向歸因、信心度/健康度五段。無法識別的自然語言會回退到 `clens why --path <p>`。

## 6. 可選 Jev／大型語言模型輔助分析

確定性的五段式因果鏈始終是事實來源。你可以選擇讓 Jev 或相容端點解釋已提交的證據鏈：

```powershell
clens assist --enable --provider jev --endpoint https://your-jev-endpoint.example/v1/chat/completions --model jev-causal
$env:CAUSATIVELENS_LLM_API_KEY = '只在目前終端使用的金鑰'
clens why --path config.yaml --assist
```

也可以使用 `--api-key-stdin`。金鑰永遠不會寫入 `settings.json`；輔助層只接收受限、唯讀的證據鏈。路徑預設脫敏，`raw_quote` 預設不傳送；若模型引用證據鏈不存在的斷言或事件，結果會標記為未建立證據關係。

GUI 的「設定」提供相同的 Jev/OpenAI-compatible/Anthropic-compatible/Ollama 選項，以及 token、逾時、脫敏、自動分析、時間線更新與保留數量等客製化項。「查詢 → 輔助分析」與 CLI 使用同一個 daemon RPC，不能改變履約判定、執行工具或啟用 v0.2.0 介入層。

## 7. 開啟與回放

目前 `open` 不讀取指定 `.cllens`；replay 比較輸入 JSON 陣列，不代表資料庫工作階段恢復已完成。

```powershell
clens open path\to\session.cllens
clens replay --baseline baseline.json --branch branch.json --json
```

v0.1.2 的回放是唯讀疊加；反事實模擬屬於 v2。

## 8. Harness 與排查

通用 JSONL parser、tail、quarantine 與哨兵有函式庫實作，廠商自動輸入尚未接通。直接 RPC 繞過 parser，健康計數零不能證明輸入完整。目前沒有 `clens adapters doctor` CLI 命令。`CL-1001` 與 `CL-2001` 的完整執行期故障處理也須依實際接線驗收。

## 9. 從原始碼建置與解除安裝

```powershell
cargo fmt --all -- --check
cargo test --workspace --offline
cargo clippy --workspace --all-targets --offline -- -D warnings
powershell -ExecutionPolicy Bypass -File installer/build-payload.ps1 -Arch x64 -Version 0.1.2
powershell -ExecutionPolicy Bypass -File installer/build-installer.ps1 -Arch x64 -Version 0.1.2
& "$env:LOCALAPPDATA\causativelens\uninstall.exe" /S /NORESTART /CLEANUSERDATA
```

E2E 關卡會檢查檔案、登錄、PATH、`.cllens` 關聯與捷徑全部清空。正式 Release 仍需 Trusted Signing、SBOM、確定性建置證據與乾淨 VM 矩陣。
